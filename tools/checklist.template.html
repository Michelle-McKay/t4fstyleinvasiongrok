Iron March art

How this works

  1. Lock the look first. Make your favourite Military Complex tier 1 image. From then on, attach that image as a reference to every prompt, so the whole set matches.
  2. Open a section, tap Copy prompt and paste it into your image tool. Each prompt already carries the full style.
  3. Save the result with the exact file name shown (tap Copy name). PNG or JPG is fine.
  4. Send them to Claude in the project thread, up to 5 images per message. Claude cuts out backgrounds, resizes, commits and merges them.

Look: bright, clean, modern industrial. Light grey and off-white panels, sand, brass and orange accents, glowing blue lights. No rust, grime or clutter. Every prompt asks for a flat magenta background, which Claude removes. Never use a grey checkerboard "transparent" background: it gets baked in as real pixels and cannot be removed cleanly.

Old dark images: items tagged "old look" are in the game but from the first dark set. They stay until you send a clean replacement under the same name.
